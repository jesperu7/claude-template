# Forbidden / Legacy Areas

*Unconditional rule — loads every session.*

## What goes in this file

The parts of the codebase Claude must never touch, import from, or copy patterns from — plus, where
useful, the modern replacement so Claude heads toward the right target. If there's no legacy yet,
keep the file with a short "none currently" note so the always-on slot exists for later.

## FILL IN — list yours

> - **Never touch:** directories/modules scheduled for removal; generated files (edit the source + regenerate).
> - **Never copy patterns from:** old code that still exists but represents the pattern you're leaving behind.
> - **Migrating away from → toward:** name the old pattern and its current replacement, so when Claude
>   meets old code it flags it for migration instead of extending it.
