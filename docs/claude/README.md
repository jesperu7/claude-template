# Claude Guides — Human Index

Deep-dive guides for this project. These are **read on demand** by Claude (not auto-loaded)
and are also meant for humans onboarding to the codebase.

Every guide listed here should also appear in the `DETAILED GUIDES` index in the root `CLAUDE.md`.
The SessionStart hook warns if an indexed guide is missing, or if a guide here isn't indexed.

| Guide | Covers |
|---|---|
| `architecture.md` | Layers, dependency injection, where logic lives |
| `state-management.md` | State patterns, how state flows |
| `testing.md` | Test strategy and structure |
| `code-style.md` | Naming, file organization, formatting rationale |
| `common-violations.md` | Anti-patterns checklist |

> Delete any guide you don't need and remove it from both this table and the CLAUDE.md index.
