Skills & commands

On /invoke

You trigger these by typing /name. They run in the main conversation (unlike subagents, which the orchestrator delegates to and which can't be user-invoked or nested).

/command

Review pipeline. Applies unconditional + matching path-scoped rules; runs the validator as a non-blocking Setup Warnings pre-check. Tailor the analyze step to the stack; teams with budget can fan out to parallel reviewers.

What survives /compact

  • Re-injected: CLAUDE.md, unconditional rules, auto-memory index
  • Not re-injected: path-scoped rules & nested CLAUDE.md (reload on next matching file read), guides, memory topic files
  • This is why the full ZERO-TOLERANCE list lives in the unconditional zero-tolerance.md — it survives compaction

Maintenance & gotchas

  • New rule: universal → no frontmatter; area-specific → paths: YAML list (cover singular and plural dir names)
  • Renaming a folder can silently orphan a rule glob — the hook / /check-rules will warn
  • New guide: add it to CLAUDE.md's DETAILED GUIDES index or it shows as an orphan
  • Verify anytime: /check-rules or bash .claude/hooks/validate-claude-setup.sh
